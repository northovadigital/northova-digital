# China Doll Restaurant — 3-Point Website Improvement Plan

## 1. Build a Stronger Branded Website Presence

Replace the current basic Wix-style presentation with a more professional restaurant website that uses consistent branding, clearer navigation, and a stronger mobile experience.

## 2. Create a Structured Digital Menu

Add a well-organized digital menu with clear categories, item names, pricing, and easy mobile access so customers can explore the restaurant's offerings without confusion.

## 3. Improve Ordering and Contact Access

Add prominent buttons for online ordering, phone calls, directions, and contact information so customers can quickly take action from any page.

## Expected Business Impact

- Stronger trust and brand credibility
- Easier menu browsing on mobile devices
- More direct customer actions
- Better overall online presentation
